# Processos Estocásticos

Trabalhos computacionais da disciplina de Processos Estocásticos - Engenharia de Computação & PPGETI, Universidade Federal do Ceará (UFC).

## Estrutura do Repositório

- **tc1/** - Trabalho Computacional 1: Análise de Séries Temporais de Precipitação
- **tc2/** - Trabalho Computacional 2: Simulação de Processos Estocásticos e Análise Estatística
- **tc3/** - Trabalho Computacional 3: Análise de Sinais Periódicos, Ruído e Filtragem Digital

## Conteúdo de Cada Trabalho

Cada pasta `tcX/` contém:
- `enunciado_tcX.pdf` - Enunciado do trabalho
- `notebook_tcX.ipynb` - Implementação em Jupyter Notebook
- `relatorio_tcX.pdf` - Relatório final em LaTeX

## Ferramentas Utilizadas

- Python 3
- NumPy, SciPy, Matplotlib
- Jupyter Notebook
- LaTeX (Overleaf)
